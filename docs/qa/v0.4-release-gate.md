## 4. Auditoria de Segurança Local-First e Invariantes

- **Zero CDNs / Zero Telemetria:** Nenhuma chamada de rede externa, dependência remota ou script CDN embutido. Todos os pacotes e estilos operam em confinamento local estrito.
- **Path Fencing Absoluto:** Todo acesso a arquivos no backend e no frontend é rigidamente limitado ao diretório raiz do workspace ativo, impedindo ataques de travessia (`../`) ou escrita fora do perímetro autorizado.
- **Invariante `INV-DESKTOP-LAUNCHER-ENV`:** Mantida e verificada nos launchers `.desktop` locais do Ubuntu, prevenindo falhas de inicialização e problemas de renderização sob Wayland (`GDK_BACKEND=x11 WEBKIT_DISABLE_DMABUF_RENDERER=1`).
- **Resiliência de Salvamento:** Gravação atômica (`tmp -> fsync -> rename`) com hash de verificação de concorrência, captura atômica de histórico local e salvamento resiliente a falhas secundárias.
