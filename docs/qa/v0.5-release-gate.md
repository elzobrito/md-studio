## 3. Matriz de Capabilities v0.5 Validadas

Todas as capabilities mandatórias da onda v0.5 foram implementadas, testadas e governadas:

1. **`MD-V05-045` — Import Fidelity Classes:**
   - Contrato estático de expectativa estrutural por formato (`High` para HTML/DOCX/EPUB, `Intermediate` para PPTX/XLSX, `Best Effort` para PDF, `Unknown` para fallback). Desacoplado de scores estéticos subjetivos (`tests/import/import-fidelity.test.ts`).
2. **`MD-V05-042` — Import Hub:**
   - Hub unificado de importação de documentos com validação de caminhos e dispatch de conversão (`tests/import/import-hub.test.ts`).
3. **`MD-V05-043` — MarkItDown Adapter:**
   - Adapter offline e local-first para conversão multimodal de documentos sem chamadas externas (`tests/import/markitdown-adapter.test.ts`).
4. **`MD-V05-044` — Import Preview Modal:**
   - Modal de pré-visualização de importação com visualização split e relatórios categóricos de fidelidade (`tests/import/import-preview.test.ts`).
5. **`MD-V05-046` — Publishing Engine:**
   - Motor unificado de publicação com múltiplos alvos, suporte a cancelamento atômico e orquestração assíncrona (`tests/publishing/publishing-engine.test.ts`).
6. **`MD-V05-047` — HTML Autocontido:**
   - Exportador HTML 100% autocontido com CSS editorial embutido, KaTeX math e diagramas SVG vetorizados (`tests/publishing/html-self-contained.test.ts`).
7. **`MD-V05-048` — EPUB 3 Packaging:**
   - Gerador atômico de EPUB 3 com `nav.xhtml`, TOC, confinamento estrito de assets locais e slots SVG (`tests/publishing/epub-export.test.ts`).
8. **`MD-V05-049` — Editorial Fallback:**
   - Tratamento resiliente a nós complexos, renderizadores indisponíveis e diagramas inválidos sem drop silencioso de dados (`tests/publishing/editorial-fallback.test.ts`).
9. **`MD-V05-050` — PDF Dedicated Exporter (Reserva Futura):**
   - Classificação formal como reserva futura / não impeditivo para a release v0.5. O mecanismo canônico legado de impressão/PDF permanece plenamente funcional.
10. **`MD-V05-051` — Mermaid Explorer:**
    - Catálogo de diagramas do documento ativo consumindo `MetadataIndex`, com navegação bidirecional e zoom modal (`tests/diagrams/mermaid-explorer.test.ts`).
11. **`MD-V05-052-SPIKE` — Spike e ADR de Diagram Engines Adicionais:**
    - ADR registrada em `docs/spec/ADR-diagram-engines.md`. Aprovação de `@hpcc-js/wasm-graphviz` e `wavedrom`; postergação justificada de D2 (tamanho de bundle WASM excedendo budget offline).
12. **`MD-V05-052` — Diagram Engines Adicionais:**
    - `DiagramEngineRegistry` local extensível, lazy loading dos módulos Graphviz/WaveDrom e sanitização SVG estrita (`tests/diagrams/diagram-engine-registry.test.ts`).
13. **`MD-BUILD-LOCAL-010` — Build Desktop Local:**
    - Compilação dos bundles de frontend e binário nativo com verificação das invariantes de ambiente Ubuntu/Wayland.
14. **`MD-TRACE-V05-001` — Reconciliação TCG Baseline G4:**
    - Arquivamento da baseline G3 em `snapshots/g3-b13ad6b.json`, geração do delta em `g4-graph-delta.md` e compilação do grafo com 0 críticos.

## 4. Auditoria de Segurança Local-First e Invariantes

- **Zero CDNs / Zero Telemetria:** Nenhuma dependência externa carregada em tempo de execução. O bundle de produção Vite (`dist/`) contém 100% dos assets locais (KaTeX, Cytoscape, Mermaid, Graphviz WASM e WaveDrom).
- **Path Fencing Absoluto:** Todas as operações de importação e publicação respeitam o perímetro estrito de segurança do workspace. Tentativas de escape de diretório (`../`) são rejeitadas preventivamente no backend Rust.
- **Invariante `INV-DESKTOP-LAUNCHER-ENV` e Hotfix de Startup:** Confirmada e fortalecida com `src-tauri/src/main.rs` e `src-tauri/src/lib.rs` assegurando fallback precoce e estrito para `GDK_BACKEND=x11` e `WEBKIT_DISABLE_DMABUF_RENDERER=1` em tempo de execução no Linux/Ubuntu (`ISSUE-MD-V05-BLANK-WINDOW-001` resolvida via `MD-HOTFIX-V05-BOOT-001`). Novo gate contínuo `scripts/desktop-smoke-test.sh` aprovado.
- **Segurança de Dependências:** `pnpm audit` executado com zero vulnerabilidades. Registrada a issue pré-existente `ISSUE-MD-SEC-GIT2-ADVISORY-001` em `git2 0.20.4` (isolada em tarefa própria de hotfix conforme lição aprendida LES-0005).
